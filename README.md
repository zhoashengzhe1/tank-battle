# 坦克大战 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 编写的经典坦克大战（Battle City 风格）游戏，单文件即可运行，无需任何依赖。

## 玩法

- 控制你的坦克，**保护下方的基地（鹰）**，消灭所有敌军坦克即可过关。
- 基地被摧毁或生命耗尽则游戏结束。
- 消灭敌军有概率掉落道具：⭐ 升级、🛡 护盾、❤ 生命、💣 全屏炸弹。

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | 方向键 `↑↓←→` 或 `W A S D` |
| 开火 | `空格` 或 `J` |
| 暂停 | `P` |
| 静音 | `M` |

手机 / 触屏设备会自动显示虚拟方向键。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

也可以起一个本地静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 特性

- 3 张关卡地图（砖墙、钢墙、水域、树林，随关卡循环）
- 敌军 AI、出生点、多敌并发
- 得分、生命、关卡、剩余敌军 HUD
- 道具系统（升级 / 护盾 / 生命 / 炸弹）
- Web Audio 合成音效
- 触屏虚拟方向键
- 纯原生实现，无外部依赖
